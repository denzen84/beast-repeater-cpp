# beast-repeater

**beast-repeater** — это универсальный сплиттер и ретранслятор потоков данных ADS-B. Программа поддерживает форматы **Beast Binary**, **AVR** и **AVRMLAT**, принимая данные от одного или нескольких источников, транскодируя их "на лету" и рассылая множеству потребителей в требуемых форматах.

Приложение является современной, легковесной и поддерживаемой альтернативой (с ограниченным, но достаточным для большинства задач функционалом) для широко известного приложения `modesmixer2`, разработка которого, к сожалению, была прекращена его автором.

## ✨ Особенности

* **Множественные источники и получатели**: Поддержка одновременной работы с несколькими входами и выходами.
* **Автоопределение формата**: Входящий формат определяется автоматически по префиксу сообщения:
  * `0x1A` → Beast Binary
  * `*` → AVR Standard (`*HEXDATA;`)
  * `@` → AVR MLAT (`@TSHEXDATA;`)
* **Гибкое транскодирование**: Встроенная матрица преобразования между форматами (Beast ↔ AVR ↔ AVRMLAT) с корректной обработкой кадров конфигурации и временных меток.
* **Поддержка Keepalive**: Опциональная отправка heartbeat-сообщений каждые 60 секунд для неактивных Beast-выходов (флаг `--keep`).
* **Высокая производительность**: Написан на современном C++20 с использованием эффективных структур данных и минимальным оверхедом.

## 📦 Зависимости

Для сборки проекта вам потребуются:
* Компилятор C++ с полной поддержкой стандарта **C++20** (GCC 11+ или Clang 14+).
* **CMake** версии **3.25** или выше.
* Библиотека **pthread** (в Linux обычно входит в стандартный пакет разработки, например, `build-essential` в Ubuntu/Debian).

## 🛠️ Установка зависимостей и сборка

### 1. Установка зависимостей (пример для Ubuntu/Debian)
```bash
sudo apt update
sudo apt install build-essential cmake
```
*(Для Fedora/RHEL: `sudo dnf install gcc-c++ cmake`)*

### 2. Клонирование и сборка проекта
```bash
# Клонируйте репозиторий
git clone https://github.com/denzen84/beast-repeater-cpp.git
cd beast-repeater

# Создайте директорию для сборки и перейдите в неё
mkdir build && cd build

# Сконфигурируйте проект с помощью CMake
cmake ..

# Соберите проект
make
```
Скомпилированный исполняемый файл `beast-repeater` будет находиться в директории `build/`.

## 🚀 Примеры использования

**Пример 1:** Получение данных с удаленного приемника и раздача на три разных порта в разных форматах с включенным keepalive:
```bash
./beast-repeater --inConnect 192.168.1.10:30005 \
                 --outServer beast:30005 \
                 --outServer avr:30002 \
                 --outServer avrmlat:30003 \
                 --keep
```

**Пример 2:** Работа в качестве локального сервера, принимающего подключения и перенаправляющего поток в агрегатор:
```bash
./beast-repeater --inServer 30002 \
                 --outConnect beast:aggregator.local:10001
```

Для просмотра полной справки по всем доступным опциям используйте флаг:
```bash
./beast-repeater --help
```
